# WriteWise 教师工作台设计

采用 frontend-design 与 vercel-react-best-practices 的设计与实现原则。

视觉主题：教案像一张认真批注的课程工作纸；工作台按教师的备课、教学、复盘顺序组织。

色板：墨蓝 #203448，教学青 #087F78，纸白 #FFFFFF，冷灰 #F4F7F9，边线 #DFE7EB，复盘琥珀 #A76822。

字体：中文使用系统微软雅黑或苹方；英文课程主题使用 Georgia；连续正文 16px，控件 14px，辅助信息 12px。

布局：左侧固定导航，顶部上下文，主体左对齐；首页以当前教案和教学闭环为主，列表按课程内容分组。编辑器采用正文加 AI 辅助面板。保留足够留白，不使用装饰性渐变或无意义统计。

备课流程有实际的四步编号；教案阶段有真实课时线。标题、状态、操作的层级分别以字重、语义色和填充区分。抽屉和弹窗用 Radix 的键盘与焦点管理。

对初始方向的审查：避免把首页切成一排相同的指标卡。首页的重点是继续真实课程备课，旁边呈现关联资料，下面显示课程清单。卡片形状和密度按工作内容变化。

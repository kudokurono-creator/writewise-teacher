参考文件有 4 页、1 个节、3 个主体表格，教学过程在第一个表格的末行内嵌一个四列表格。已检查全部参考页。

页面为 A4：11906 × 16838 twip，上下边距为 935 / 1091 twip，左右边距各 1134 twip。保留原模板的标题 15 pt、黑色字、加粗居中，以及主体文字、表格标签和教学过程的原字体和段落格式；主体教学说明主要使用楷体 10 pt。表格分区黑底白字，标签灰底（E6E6E6 / E7E6E6），细黑色单线边框 4 个八分之一磅单位。无新增页眉页脚。

基本信息表格原始列宽为 862 / 2317 / 1330 / 2331 / 720 / 2078 twip。教学课题原合并单元格填入名称；时长填入课程分钟数；授课年级同时填写年级和班级；设计者由已登录教师姓名填写；学号保持空白。教材、单元、写作主题和体裁写入教学内容分析。不存在的数据不虚构。

课程标准、教学内容分析、学情分析、教学目标、重点、难点、设计思路、流程、板书、学习资料、教学支持材料、评价、其他和反思均对应原表格的已有槽位。槽位用单个文本 run 内的 `{{TOKEN}}` 定位。现有字段对应不到的课程标准、设计思路增加可编辑字段，并兼容旧版本空值。课程标准缺少原文时提示教师补充；设计思路缺省时汇总已有方法和阶段设计意图。

教学过程选择原模板明确允许的表格形式，删除其示范文字与另一种文字形式。原四列及顺序保持：教学环节（包含时长）、教师活动、学生活动、设计意图；列宽为 1923 / 2764 / 3007 / 1924 twip。按阶段复制数据行，1–15 个阶段，允许随实际内容分页。表格从嵌套单元格提升到正文以支持 Word 跨页重复表头，并居中对齐；不改变课程内容。删除空表单为占位设置的行高，保留反思页的填写空间。板书与教学资源、反思仍遵循原模板的独立页模式。

`scripts/prepare-export-template.py` 从转换副本生成 `public/templates/classroom-design-2026.docx`。生产服务直接填充这个派生模板，不需要本机 Word、Python 或原 DOC 文件；部署时 public 目录随现有 Docker 配置复制。Next.js 导出路由的追踪文件已包含该资产。

运行时仅修改 `word/document.xml` 和 `docProps/core.xml`；其他包部件逐字节保留，通过单元测试验证。文本转义 XML 字符、控制字符和模板形状的文字，保留换行，不插入用户提供的 XML。原模板说明文字不进入最终教案，版本中不存在的课程标准不会被凭空补写。

原始包大小和哈希证据保存在 `output/repair-qa/template-package-evidence.json`。最终示例用 Word 只读导出 PDF、Poppler 渲染，逐页检查 4 页的中文、列宽、边框、重复表头、分页、板书和反思留白。内置 `render_docx.py` 因此 Windows 环境没有 bundled soffice.exe 无法完成，未安装办公软件或调用本机 LibreOffice。

## Word 可视化验收

导出的是正式 OOXML 文档，而非修改扩展名的 Markdown。已用本机 Microsoft Word 16.0 以只读方式打开，转为 PDF，并使用 Poppler 渲染逐页检查。

修复了中文字体 API 选项、时间列过窄及教学阶段跨页拆分的问题。检查中文字符、标题、表格列宽、段落换行、重复表头与分页，未发现文字重叠或截断。标准示例教案为 3 页，具体页数随内容变化。

内置 render_docx.py 的 LibreOffice 渲染在此 Windows 环境因缺少 soffice.exe 无法运行；本次使用已安装的 Microsoft Word 完成实际打开和排版验收。未安装额外办公软件，也未修改原有 DOC 模板。

## 当前限制

- 没有提供真实模型与搜索密钥。真实 AI／Embedding／Tavily 联调未执行；Provider 的响应格式、修复和流式行为使用模拟 HTTP 响应测试。
- 演示 AI 不代表真实教学分析质量；演示 Embedding 不代表语义检索质量。
- 本机没有 Docker，Dockerfile 与 compose 已提供，但未实际构建容器。
- 当前验证数据库为本地持久化 PGlite PostgreSQL 运行时，未连接外部生产数据库。
- 未接入 OCR。扫描 PDF 会返回说明，需先转换。
- 导出按完整产品教案结构生成，未复刻目录中旧 DOC 模板的排版。
